
# Agronegócio Premium

## Descrição
Plataforma moderna e tecnológica voltada para o setor do agronegócio, oferecendo soluções completas de inteligência artificial, agricultura de precisão, marketplace ESG, gestão rural e insights de mercado. Desenvolvido com foco em experiência do usuário, performance e design premium.

## Funcionalidades
* Dashboard agrícola com gráficos interativos
* Blog com notícias do setor
* Seção ESG com métricas de sustentabilidade
* Marketplace para negociação de insumos e máquinas
* Inteligência Artificial aplicada ao agro
* Agricultura de Precisão com drones e satélites
* Gestão Rural completa (ERP agrícola)
* Responsividade Total (Mobile First)
* Dark Mode nativo
* SEO otimizado e Schema Markup

## Tecnologias Utilizadas
* HTML5 semântico
* CSS3 (variáveis, grid, flexbox, glassmorphism)
* JavaScript (ES6+)
* Chart.js
* GSAP com ScrollTrigger
* AOS (Animate on Scroll)
* Swiper.js

## Como Executar
1. Baixe todos os arquivos (index.html, style.css, script.js, favicon.ico, assets opcionais)
2. Certifique-se de manter a estrutura de pastas (ou utilize os links CDN já integrados)
3. Abra o arquivo `index.html` em qualquer navegador moderno
